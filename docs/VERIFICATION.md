## TUI 实现与结构化样式

单账户结构化 UI 已获用户手动验收，并提交为 `417a471`。自适应视口已获用户整体可用反馈；本轮时区搜索选择和真实多账户并行运行仍需专项验收；Agent 仅做静态检查、构建和非 UI 回归，未运行 UI 自动化。既往整体确认不等于新增界面、各平台及异常路径均已验证。

- 登录、模型、设置、编辑、授权等待统一在一个 TUI；不再创建临时 readline 问答或反复切换终端模式。
- Esc 逐层返回；Ctrl+C 为全局双次退出确认，第二次无需等待当前任务结束。退出恢复终端但不停止后台；中断正在进行的续期可能需要重登。
