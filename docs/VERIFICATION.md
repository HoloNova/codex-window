## TUI 实现与结构化样式

用户已完成登录，并在本轮结构化 UI 交付后确认可用，授权作为单账户完整版本提交。以下界面实现经用户手动验收；Agent 仅做静态检查、构建和非 UI 回归，未运行 UI 自动化。用户的整体确认不等于各平台、终端组合或所有异常路径均已逐项验证。

- 登录、模型、设置、编辑、授权等待统一在一个 TUI；不再创建临时 readline 问答或反复切换终端模式。
- Esc 逐层返回；Ctrl+C 为全局双次退出确认，第二次无需等待当前任务结束。退出恢复终端但不停止后台；中断正在进行的续期可能需要重登。
- 按行差分和同步输出；同一画面零终端写入，首次/尺寸变化才清屏。目录级文件通知触发更新，合并同轮通知，5 秒兜底检查，不增加远端查询。
- 输入先重组完整序列，再交给 Node 解码；单独 Esc 本地 10ms、SSH 100ms，不完整序列短时缓冲，Ctrl+C 不被残留序列阻塞。未用自动化测量实际终端延迟。
- 模型目录按账号在前台内存缓存 5 分钟；新登录清除缓存，不改变持久化格式、凭证或启停规则。
- SGR 语义色、剩余额度渐变及低额文字标签、即将/到时时间提示、旧数据弱化、NO_COLOR 支持。
- 迟到的取消任务结果不抢回页面；F2 在各页均可暂停，设置保存可取消。
- 居中应用标题、圆角卡片、宽屏并排/窄屏堆叠的订阅与快捷操作布局；按终端高度紧凑显示，长文本按列截断并标省略，避免撑破边框。
- 登录、模型、设置、编辑和等待改为首页上的居中弹窗，背景弱化。共享按终端列宽计算的布局与覆盖机制，保留中文/宽字符和 SGR 样式。
- 首页移除“开窗复查”，不再显示 nextRefresh 或直接照搬后台运行原因；调度规则和持久化字段完全不变。
- D 日志页：载入已有最近八条事件，在面板会话内累计最多 1000 条；按宽度折行、缓存日志行，滚轮/方向键/翻页键/Home/End 和细滚动条，翻阅历史不抢回底部。没有加入跨会话持久历史或搜索。
- 右下角无边框、3 秒文字提示，首页锚定事件卡片；覆盖区域先替换，不叠字，过期恢复原内容。Ctrl+C 第一次为红色且在确认窗口内优先显示；其他按键及时清除退出提示。
- 日志、模型和等待窗口启用 SGR 鼠标滚轮报告，兼容吞掉旧式鼠标报告，防止坐标变成普通操作键；关闭时恢复鼠标和终端模式。未使用自动化模拟键盘或鼠标。
- 未添加多账户入口，未更改账号、设置、调度或日志的后台存储格式；未重启用户正在运行的前台/后台。

单账户界面已获用户整体确认；仍可按 README 中的验收步骤检查不同终端尺寸、平台及异常路径。
