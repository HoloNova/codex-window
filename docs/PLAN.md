## 主线

独立登录 → 保存/续期凭证 → 查询额度 → 按规则等待 → 必要时发送一次 hello → TUI 展示。

- 每个账号一个明确选择的订阅模型；账号凭据和运行状态隔离，不自动换号，不发现或预热其他额度池。
- 新配置默认运行设备时区、04:30–19:30、每 30 分钟查询；旧账号保留等价时区，支持必要的时区、时段和间隔设置。
- 超过一个查询间隔才重置：等待；临近重置：安排重置后 90 秒复查。
- 复查发现已有新窗口：不发送。窗口空闲、额度允许且已启用时才发送。
- 数据缺失、查询失败或限制未知时不猜测；不保留固定时间兜底和五分钟重发链。
- 发送前持久化待确认标记，超时/结果不明确不自动重发。观察到活动窗口或用户明确启用并复核后解除。
- 初始暂停；登录和实际业务设置修改暂停。打开 S 或切换语言不暂停。关闭面板不停止后台；暂停只禁止发送，仍可查询。

## 实现顺序

1. 直接 HTTP：设备码及浏览器登录、凭证续期、额度查询、单次请求。
2. 一份后台进程、每账号独立串行任务，由实际定时器和文件通知唤醒；保留 30 秒低频兜底、时间规则及防重复发送。
3. 最小 TUI：登录、账号/模型/时区选择、设置、额度、状态、启停；不展示内部复查机制。
4. 类型检查和本地模拟接口/进程测试；真实账号和终端由用户手动验收。

## 已确认的 TUI 规则

- 所有页面在同一个 TUI 内，统一输入所有权，不混用临时终端问答。
- Esc 返回上一步；主页不退出。Ctrl+C 第一次提示，3 秒内第二次退出前台；后台不随面板退出。
- 设置使用草稿；编辑项 Esc 放弃本项，设置页 Esc 放弃未保存草稿；保存后实际变动的账号保持暂停，同步开关也在保存时生效。
- 只更新变化的行；首次/尺寸变化才完整重绘，使用同步输出避免中间帧闪烁。
- 普通按键立即解析，单独 Esc 的序列判断窗口为本地 10ms / SSH 100ms；保留 UTF-8 和完整按键序列重组。
- 状态变化由文件通知触发，5 秒兜底检查；模型目录按账号在前台内存缓存 5 分钟，不因命中缓存而续期或等待账号锁。
- 额度显示剩余百分比，绿→黄→红；低于阈值同时用文字标明。时间、等待、警告、失败、暂停使用统一语义色，支持 NO_COLOR。

## 本轮已确认的结构化 TUI

- 顶部居中显示 `Codex Window Autorefresh`，各模块使用圆角矩形；宽屏订阅卡片与快捷操作并排，窄屏上下排列，文字换行、快捷键自动分行。不设置最低尺寸门槛，空间不足时首页和弹窗滚动，极小窗口压缩边框、标题与留白，不禁用操作。
- 订阅卡片顶部为当前账号与订阅信息，显示所选模型、五小时/周剩余额度及重置时间、启停状态；账号/模型、两种额度和运行状态分组留白，额度与重置时间分行，不因终端高度不足而挤成一行。不展示“开窗复查”等内部术语；按后续确认新增“下次动作”，读取后台已保存的检查计划，明确是否仅查询及符合条件才开窗，不承诺到点必发；后台规则不变。
- 下方为事件卡片，固定预览最近 3 行，不随窗口高度扩展；宽屏时“按 D 查看详细日志”置于卡片右上角，窄屏时保留在预览下方。日志独立页面支持滚轮、方向键、翻页键、Home/End 和滚动条；翻阅历史时不自动跳回底部。
- 本轮只使用现有八条事件快照，在前台会话内继续累计，最多 1000 条；不修改后台状态格式或加入持久日志存储。日志搜索和跨会话完整历史后续再定。
- 登录、模型、设置、字段编辑和等待均为自适应居中弹窗；共享滚动视口，导航与返回时跟随选中项，编辑时跟随光标。Shift+↑↓ 可翻阅内容，Esc 逐层返回，双 Ctrl+C 全局退出不变。
- 提示为右下角无边框纯文字，默认 3 秒；首页在可见事件卡片右下角，事件区不在视口内时靠终端右下角，可覆盖内容但不得叠字。成功绿、警告黄、错误红、普通反馈青色；第一次 Ctrl+C 的退出确认同样为红色提示。
- 快捷操作不重复显示 A/D，保留账号/事件卡片上的标注和按键；当前账号已启用时仅显示 I/F2 暂停，已暂停时仅显示 R 启用。宽窄布局复用同一操作列表，实际键盘绑定不变。
- 单账户 UI 已验收；本轮新增 A 切换/添加账号弹窗，切换只显示本地缓存，不影响其他账号运行，不以覆盖现有登录冒充账号切换。
- 不运行 UI 自动化，不操作用户登录、设置、启停状态或现有进程；业务和非 UI 回归使用临时目录、模拟 HTTP 验证。

## 已批准的多账户扩展

- 原账号保留根目录凭据与状态，新增账号独立目录；按真实身份去重，新增账号默认暂停。
- 后台保持一份进程，各账号循环独立，慢请求/失败不阻塞其他账号。TUI 和无头命令的账号操作明确作用对象；X/stop 为全局停止。
- 设置各自保存，提供默认开启的全局同步开关。保存时同步模型、时区、时段、间隔，不复制凭据、额度、启停或待确认；配置实际变化者暂停，需逐个启用。
- 不强制重登、不自动替换正在运行的单账户后台；先提示，再由用户安排关闭旧前台和后台、重新启动。未执行真实切换。
- 账号隔离、并发、同步、取消和停止使用本地模拟接口与临时目录验证；新增 TUI 仍由用户手动验收。

## 已批准的配置与后台性能改造

- 用户配置独立保存为每账号 config.json，运行结果/待确认保存在 state.json v2；凭据不搬迁。内部合并视图不在磁盘重复存配置。
- 允许手工编辑配置；错误明确提示并阻止该账号发送。编辑单账号不触发全局同步，TUI/CLI 保存仍遵循同步开关。
- 新默认时区取运行环境，TUI 使用固定时区目录搜索选择，旧别名仅迁移时等价规范化。读取校验不重复构造 Intl，调度格式化器按时区复用。
- 移除后台每账号的 250ms 主轮询/停止监视及账号池的 250ms 扫描，改为到点定时器、目录级文件通知及 30 秒兜底；面板是否打开不影响后台运行。
- 最终发送前重读配置与运行状态，配置快照变化也使旧查询许可失效；不要求手工编辑者修改内部控制计数。错误配置不能妨碍全局停止，修复文件不自动绕过已持久停止。
- 旧后台存活时不迁移；请求停止时仍写旧格式，安全退出后再拆分配置。迁移和真实后台切换需要另行安排，本轮未执行。
- 本地合成测试覆盖文件职责、迁移、手工改动、停止和通知/定时唤醒；资源实验不代表真实进程已优化。UI 搜索及真实 CPU/RSS 待手动验收。

## 已批准的发行包、Windows 托盘与语言

- 首版发行目标为 Windows x64 和 Linux x64（glibc 常见发行版），不提供 macOS 发行包或支持承诺。源码入口保留，发行包自带 Node，无须用户安装 Node/npm。
- CI 负责编译、测试、生成包与校验和；默认只产出工作流 artifacts，不自动创建 Release。提交、推送和真正发布仍需单独授权。
- 使用 Node 24 官方 SEA；仅构建阶段增加 bundler/resource injector，将 ESM 编译为单一 CommonJS 入口。后台拉起兼容源码和打包模式，包内不含账户数据。
- Windows 使用 Win32 原生托盘小启动器，不引入 Electron。双击直接打开 TUI 并保留托盘，后续双击或托盘菜单重新打开/尝试唤回已有面板；关闭面板不停止后台，重复打开不创建第二个面板。退出应用仅协作关闭本数据目录的进程，排空已开始的凭据保存/请求，不强杀、不改变账号启停设置；再次启动沿用原状态。
- 新增应用级退出控制与前台/后台/无头操作会话注册，与现有 X/stop 的“暂停所有账号并停止后台”区别开。退出持锁到会话排空，排队旧启动不能绕过更新的退出；最终执行直接检查退出许可，不只依赖通知。新旧后台协议不兼容时提示用户手动停止旧版，不擅自替换。
- 默认 English，设置可选简体中文；不按时区/系统语言自动切换、不强制首启语言选择。语言是独立全局显示偏好，不受账号设置同步影响，不因切语言暂停账号；业务配置实际变动后仍按原规则暂停。
- 使用轻量消息目录统一界面、帮助、提示、错误和新日志；旧历史文本保留原文，模型 ID/授权码/地址等参数不作词语替换。语言切换不重写凭据或调度设置；坏语言文件提示并回退英文，不覆盖文件，不阻断安全停止。
- 自动验证仅限非 UI 业务、退出协议、偏好、打包和原生编译。TUI/托盘交互只做人工验收；本机无 Windows 原生编译环境，其编译验证交给 CI，不把未执行 CI 声称为通过。

## 边界

- 不依赖或读取 Pi、Codex CLI、旧 Rust 程序的凭证。不安装/修改线上服务。
- 凭据继续以明文私有文件保存，不增加密钥管理。新登录只请求 `openid profile email offline_access`；不申请未使用的连接器权限，不在拒绝后静默扩大权限，已有授权不会被自动撤销或缩减。
- 默认独立数据目录 `~/.codex-window-node`；`--home` / `CODEX_WINDOW_HOME` 可指定。
- 状态使用本地 JSON；凭证单独私有保存，不进入日志。后台进程与面板通过文件交互，不增加常驻 HTTP 服务。
- 运行时仅使用 Node.js 标准库；TypeScript、Node 类型、esbuild 和 postject 仅为开发/打包依赖。
- 不增加 Web、数据库、插件框架、自动更新、自动开机启动、系统通知推送平台或上游旧格式兼容层；仅迁移本工具已发布的本地状态。
- 用户已授权本轮交互、授权范围与图标改动提交、推送并发布第二个预览 Release；不覆盖上一发行版，不包含部署、清理旧参考目录、真实登录或发送。后续以上操作仍需单独授权。
- 旧参考目录在新版开发完成并经用户验收后再清理。
